# PDF解析器测试套件

这个测试套件用于验证PDF解析器的各项功能，确保代码质量和稳定性。

## 📁 目录结构


## 🧪 测试内容

### 单元测试 (Unit Tests)

1. **基础初始化测试** - 验证PDFParser类的各种初始化方式
2. **CSV元数据解析测试** - 测试CSV文件解析和公司名称处理
3. **PDF文件检测测试** - 检测指定目录中的PDF文件
4. **单个PDF解析测试** - 测试单个文件的解析功能
5. **批量PDF解析测试** - 测试批量处理功能
6. **错误处理测试** - 验证异常情况的处理
7. **JSON报告处理器测试** - 测试报告生成组件

### 集成测试 (Integration Tests)

1. **性能基准测试** - 对比单线程和多线程处理性能
2. **完整流程测试** - 测试从PDF输入到JSON输出的完整流程
3. **真实数据测试** - 使用实际的PDF文件进行测试
